One hilarious line, written for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun.

> My smartwatch says my heart rate spikes every time I check my bank balance. It's the only cardio I get.

`main.py` (pure Python standard library) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
